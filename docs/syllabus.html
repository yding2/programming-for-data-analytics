🎯 Course Objectives

By the end of this course, students will be able to

  • Become familiar with the fundamental statistical concepts underlying analytics, including the basics of data, samples, populations, randomness, modeling of random phenomena, and steps required for extracting information from data in general.

  • Recognize which descriptive statistics and predictive models are typically used in various applied scenarios through illustrative use cases.

  • Gain practical skills in programming in R for analytics, aiming to implement systematic data analysis algorithms and obtain information from them.

  • Understand how to perform data preprocessing and visualization techniques and generate descriptive statistics.

  • Apply predictive models to data and evaluate models using diagnostics and model fitting tests.

📝 Midterm Exam

The midterm exam will assess your understanding of the material covered during the first half of the course, including

  • R programming
  • Descriptive statistics
  • Probability
  • Random variables
  • Statistical inference

The exam will primarily consist of problems similar to homework assignments and lecture examples.

A review session will be held before the exam.

📈 Final Project

The final project is completed in groups of up to three students.

Each group will select a real-world dataset and perform a complete data analysis using the methods learned in this course.

The project should include

  • Data preprocessing and cleaning
  • Exploratory Data Analysis (EDA)
  • At least one hypothesis test
  • At least one regression model
  • Interpretation of results
  • A reproducible R Markdown report

Each group will also give a 15-minute presentation followed by 5 minutes of questions.

Detailed project requirements, milestones, grading rubrics, and submission instructions are available on the Final Project page.

1 Aug. 17, 19 Course Introduction & R Foundations — R/RStudio, R Markdown/Quarto, basic R programming, importing and working with data
2 Aug. 24, 26 Introduction to Statistics & Probability — populations and samples, descriptive statistics, probability concepts and rules

6 Sept. 21, 23 Statistical Inference I — confidence intervals, hypothesis testing, inference for a single mean

8 Oct. 5, 7 Statistical Inference III — inference for proportions and variances, review of statistical inference
9 Oct. 14 Midterm Exam
10 Oct. 19, 21 Association Between Variables & Introduction to Statistical Learning — covariance, correlation, prediction, training and test data
11 Oct. 26, 28 Linear Regression — simple linear regression, least squares, inference for regression coefficients, multiple linear regression
