Random Variable

Variable: A variable is a quantity that may change within the context of a mathematical problem or experiment.

Random Variable: A random variable is a numerical description of the outcome of an experiment.

Examples:

  • \(X =\) number of heads after tossing a fair coin 100 times.
  • \(Y =\) number of 6s after rolling a fair die 100 times.
  • \(Z =\) number of As in this class.
  • \(A =\) amount of time you spent watching TV every week.

Types of Random Variables:

  • Discrete random variable: take on a finite (or countable) number of values.

    Examples:

    • Sum of two dice: \(\{2, 3, 4,\ldots, 12\}\).
    • Number of children: \(\{0, 1, 2, \ldots\}\).

  • Continuous random variables: take on values in a continuum (usually an interval)。

    Examples:

    • Height: \((0,2.5)\) meters
    • Weight: \((0,200)\) pounds
    • Time: \((0,75)\) minutes

Describe a Discrete Random Variable

Tossing Coin Experiment: Toss a fair coin 3 times. Suppose we are interested in the random variable \(X =\) number of heads.How do we get the probabilities??

We know the total number of outcomes of this experiment is \(2^3 = 8\). Why?

  • \(X=0\), i.e., \(P(X=0) = P(\{TTT\}) = 1/8 = \frac{1}{8};\)
  • \(X=1\), i.e., \(P(X=1) = P(\{HTT\})+P(\{THT\})+P(\{TTH\}) = \frac{3}{8};\)
  • \(X =2\), i.e., \(P(X=2) =P(\{HHT\})+P(\{HTH\})+P(\{THH\}) = \frac{3}{8};\)
  • \(X =3\), i.e., \(P(X=3) = P(\{HHH\}) = \frac{1}{8}\)

Thus, we can have the following table \[\begin{array}{c|ccccc} x & 0 & 1 & 2 & 3 \\ \hline P(X = x) & \frac{1}{8} & \frac{3}{8} & \frac{3}{8} & \frac{1}{8} \end{array}\]

Using R to simulate this random variable

We can use sample function to generate an observation of this random variable

n <- 3
x <- c(0,1)
#1 indicates Head 0 indicate Tail
sample(x, size=n, replace=TRUE) #simulate flipping coin 3 times
[1] 0 0 1
# Here X1 is one observation
X1<- sum(sample(x, size=n, replace=TRUE)) 
X1
[1] 1
# Here X2 is another observation
X2<- sum(sample(x, size=n, replace=TRUE)) 
X2
[1] 1

PMF and Its Properties

PMF(Probability Mass Function): The values on the right of the table above are called the Probability Mass Function of the random variable \(X\).

  • \(f(x)\geq 0\) for all \(x\in R\). (PMFs are non-negative)
  • There are only finitely (or countably infinitely many) \(x\)’s for which \(f(x) > 0\). (The probability of other values are 0.)
  • \(\sum\limits_x f(x) = 1\). (The sum of probabilities over all possible values is 1.)
  • \(P(X = x) = f(x)\).

The following table is the PMF for \(X\), the number of heads tossing a fair coin 3 times. \[\begin{array}{c|ccccc} x & 0 & 1 & 2 & 3 \\ \hline P(X = x) & \frac{1}{8} & \frac{3}{8} & \frac{3}{8} & \frac{1}{8} \end{array}\]

Let’s generate a sample with size 10 of this random variable.

resultOf10rep<-replicate(10, sum(sample(x, size=n, replace=TRUE)))
resultOf10rep 
 [1] 2 2 2 0 3 0 1 1 0 1
replicate(10, sum(sample(x, size=n, replace=TRUE)))
 [1] 2 2 2 2 2 1 2 0 0 2

CDF(Cumulative Distribution Function): \(F(x)\) of a random variable \(X\) with PMF \(f(x)\) is \[ F(x) = P(X \le x ) = \sum_{t \le x } f(t), \qquad -\infty <x <\infty. \]

Example: CDF of \(X\), the number of heads tossing a fair coin 3 times \[F(x) = \begin{cases} 0 & x < 0\\ \frac{1}{8} & x < 1 \\ \frac{1}{2} & x < 2\\ \frac{7}{8} & x <3 \\ 1 & x \ge 3 \end{cases}.\]

Expected Value of a Discrete Random Variable or a Function of a Discrete Random Variable

Expected Value (Population Mean) of a Discrete Random Variable

Expected value: The expected value of a random variable \(X\) with PMF \(f(x)\) is given by: \[\mu = E(X) = \sum_x xf(x).\]

  • The expected value is a weighted average of the possible values of \(X\), weighted by the probabilities. We may interchangeably use population mean or mean, average, expectation, and expected value, and the notations \(E(X)\) or \(\mu\).
  • The expected value of a random variable can be understood as the long-run average value of the random variable in repeated independent trials.

Example: Expectation of \(X\), the number of heads tossing a fair coin 3 times is

\[\begin{align*} \mu =E(X) & = \sum_x xf(x) = 0\cdot \frac{1}{8} + 1 \cdot \frac{3}{8} + 2\cdot \frac{3}{8} + 3\cdot \frac{1}{8} = \frac{3}{2}. \end{align*}\]

This means, if we perform the experiment many many many times, and each time we record the value of \(X\) , then the average value of these observed \(X\) values is approximately 3/2. If we can perform the experiment infinitely many times, then the average value will be exactly 3/2.

Using R to generate samples with different sizes and calculate the sample mean

Recall the experiment we did, what value is the sample mean?

mean(resultOf10rep)
[1] 1.2

If we change the sample size to 1000, what’s the sample mean?

# First time
resultOf1000rep1<-replicate(1000, sum(sample(x, size=n, replace=TRUE)))
mean(resultOf1000rep1)
[1] 1.55
# Re-select the sample
resultOf1000rep2<-replicate(1000, sum(sample(x, size=n, replace=TRUE)))
mean(resultOf1000rep2)
[1] 1.551

Observation: If the sample size is large enough, the sample mean can be a good estimation for the expectation(population mean).

Variance of a Discrete Random Variable

Variance of a random variable is the expected value of a special function (\(g(X) = E[X-E(X)]^2\)) of this random variable, which measures the variability of \(X\) compared to its mean \(E(X)\).

Variance is a measure to quantify the variability/risk. Let \(X\) be a discrete random variable with PMF \(f(x)\). Then the variance of \(X\) is defined as

\[\begin{align*} \sigma^2 =var(X) &= E[(X-\mu)^2] = \sum_x (x-\mu)^2f(x)\\ &= E(X^2)-[E(X)]^2 = \sum_x x^2f(x)-\left[\sum_x^2 xf(x)\right]= E(X^2) -\mu^2. \end{align*}\]

  • It measures the mean squared distance of observations on \(X\) from its mean.
  • \(var(X)\) is always non-negative \(var(X)\geq 0\).
  • \(var(aX) = a^2var(X)\).

Example: Variance of \(X\), the number of heads tossing a fair coin 3 times is \[\begin{align*} \sigma^2 =E(X^2)-\mu^2 & = \sum_x^2 xf(x) - \left(\frac{3}{2}\right)^2\\ &= 0^2\cdot \frac{1}{8} + 1^2 \cdot \frac{3}{8} + 2^2\cdot \frac{3}{8} + 3^2\cdot \frac{1}{8} -\frac{9}{4} = \frac{3}{4}. \end{align*}\]

Using R to calculate the sample variance

What are the sample variance?

var(resultOf10rep)
[1] 1.066667
var(resultOf1000rep1)
[1] 0.7402402
var(resultOf1000rep2)
[1] 0.7521512

Observation: If the sample size is large enough, the sample variance can be a good estimation for (population) variance.
